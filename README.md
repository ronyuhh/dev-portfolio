# Developer Portfolio

A modern, responsive personal portfolio website built to showcase web development skills, selected projects, and contact information.

## Live Demo

[View the live portfolio](https://ronyuhh.github.io/dev-portfolio/)

## About the Project

This portfolio features a dark charcoal and violet visual theme, a clean layout, and responsive sections designed to provide a consistent browsing experience across desktop and mobile devices.

## Features

- Responsive design for desktop and mobile
- Dark theme with violet gradient accents
- Mobile navigation menu
- Dedicated About and Skills sections
- Featured project showcase
- Contact call-to-action
- Scroll-reveal animations
- Automatically updated footer year

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git and GitHub
- GitHub Pages

**Nexa Digital** — a responsive digital agency landing page.

## Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use a local development server.
